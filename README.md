# Otrobonita AI Labs — org defaults

This repository is the GitHub organization profile and the default community
files for public work.

- **[profile/README.md](profile/README.md)** — the public map of the org. This
  is what people see at [github.com/otrobonita-studios](https://github.com/otrobonita-studios).
- **[llms.txt](llms.txt)** — short rules for agents opening this org.
- **[REPO-STANDARD.md](REPO-STANDARD.md)** — what a public repository here must
  look like before it is judged.
- **[SECURITY.md](SECURITY.md)** — how to report a vulnerability.

The installable engineering kit is **[playbook](https://github.com/otrobonita-studios/playbook)**.
Do not copy that kit into this repository. Org shop-window rules live here;
engineering practice lives in playbook.
